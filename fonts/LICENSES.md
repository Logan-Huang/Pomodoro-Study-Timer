# Font licenses

Aura serves these fonts from this repository, so no request goes to Google Fonts. They are licensed under the [SIL Open Font License 1.1](https://openfontlicense.org), which allows bundling and redistributing them with software. Each font's full license text is in this folder.

| Font | Copyright | License text |
|---|---|---|
| Inter | © 2020 The Inter Project Authors ([rsms/inter](https://github.com/rsms/inter)) | [OFL-inter.txt](OFL-inter.txt) |
| Outfit | © 2021 The Outfit Project Authors ([Outfitio/Outfit-Fonts](https://github.com/Outfitio/Outfit-Fonts)) | [OFL-outfit.txt](OFL-outfit.txt) |
| Instrument Serif | © 2022 The Instrument Serif Project Authors ([Instrument/instrument-serif](https://github.com/Instrument/instrument-serif)) | [OFL-instrumentserif.txt](OFL-instrumentserif.txt) |

The `.woff2` files are the unmodified Latin and Latin Extended subsets that Google Fonts distributes.
